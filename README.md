In modern organizations, managing employee salary structures is a critical yet complex task. Each employee’s salary is composed of multiple components such as basic salary, allowances (HRA, DA, bonus), and deductions (tax, PF, etc.). Performing these calculations manually can lead to errors, inefficiency, and lack of scalability when dealing with a large number of employees.

The objective of this system is to develop an Employee Salary Management System using Object-Oriented Programming (OOP) principles that can:

Store and manage employee details efficiently
Automatically calculate salary components based on predefined rules
Compute gross salary and net salary accurately
Provide structured output such as salary reports or payslips
Ensure modularity, reusability, and scalability using OOP concepts

The system should encapsulate employee data and related operations within a class, promoting data hiding and abstraction. It should also allow easy extension in the future, such as adding new allowances, integrating databases, or handling multiple employees dynamically.

 Key Requirements
Accept employee details (ID, name, basic salary)
Calculate:
HRA (percentage of basic salary)
DA (percentage of basic salary)
Tax deduction
Compute:
Gross Salary
Net Salary
Display employee salary details clearly
